# InvestWise Preview

InvestWise is a teen-friendly investing education and simulator web app.

## Features

- Beginner money lessons
- ETF education
- Virtual investing simulator with searchable stock picker
- Budget simulator
- Top 100 US stock education cards with logos and company explainers
- Platform guide for Fidelity Youth, Greenlight, Robinhood, and Schwab Teen Investor
- FinCoach educational assistant

## Run Locally

This preview is a static site. Open `index.html` directly or run:

```bash
node server.mjs
```

Then visit:

```text
http://localhost:4173
```

All investing examples are simulated and for educational purposes only.
